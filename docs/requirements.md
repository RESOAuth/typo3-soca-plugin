Security limits for this version: transactions 300 seconds; eight pending per native browser session; client assertions 60 seconds; JWT clock skew 60 seconds; public metadata/JWKS cache lifetime 300 seconds; proxy payload 6144 bytes and client-ID URL 8192 bytes. HTTP has no redirects, a three-second connect bound and twelve-second cURL transfer bound after DNS resolution, with a 256 KiB body bound. Check the implementation for exact parser/key limits. Provider cache bounds are unconfirmed. There is no supported key overlap/rotation schedule or retained diagnostic data. External tokens are not stored. Default absolute local SSO session lifetime is 900 seconds, configurable 60–86400; provider-only revocation propagates through expiry until logout protocols exist. The host's native session deletion/backup policies bound physical retention of sealed expired snapshots. Published readiness remains bound to its exact revision until a covered configuration change invalidates it; a document check is never represented as a real login.
