# Security reporting

Report suspected vulnerabilities privately through the repository's GitHub Security Advisory form. Do not include tokens, private keys, callback URLs or user claims in public issues.

Version 0.1.0 is a review candidate, not an audited production release. Maintainers aim to acknowledge reports within three working days, triage within seven and publish fixes for confirmed critical/high issues before a release is promoted. No contractual response time is promised.

PHP is not supported by CodeQL. The CodeQL workflow scans GitHub Actions and the Python demonstration tools; PHP validation, adversarial protocol tests and Composer audit run separately. Independent review and OIDC conformance testing remain release gates.
